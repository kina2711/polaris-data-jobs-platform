# Crawl Job Data Pipeline — Web Portal

Next.js 15 (App Router) web portal for browsing, searching, and AI-matching Data
& AI job postings in Vietnam.

## Quick Start

```bash
npm install
npx prisma db push
npm run dev
```

Visit `http://localhost:3400`.

## Environment Variables

Copy `.env.example` to `.env` and fill in `DATABASE_URL`.
